Module 1: Input Module
Purpose: To receive the number \(n\) from the user.

Algorithm:
1. Start.
2. Display a message asking the user to enter a number.
3. Read the number \(n\).
4. Check whether the number is non-negative.
5. If the number is negative, display an error message.
6. Otherwise, pass the number to the factorial calculation module.
7. Stop.


Module 2: Factorial Calculation Module
Purpose: To calculate the factorial of the given number.

Algorithm:
1. Start.
2. Initialize factorial to 1.
3. Set counter to 1.
4. Multiply factorial by counter.
5. Increase counter by 1.
6. Repeat steps 4 and 5 while counter is less than or equal to \(n\).
7. Display the factorial.
8. Stop.



Module 3: Output Module
Purpose: To display the factorial results.

Algorithm:
1. Start.
2. Receive the calculated factorial.
3. Display the factorial in the required format.
4. Stop.
Module 4: Main Module
Purpose: To coordinate the execution of all other modules.

Algorithm:
1. Start.
2. Call the input module.
3. Receive the value of \(n\).
4. Call the factorial calculation module.
5. Call the output module.
6. Stop.
