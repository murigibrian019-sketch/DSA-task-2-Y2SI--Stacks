# Data Structures and Algorithms – Task Two

## Project Description
This project implements factorial calculations using forward and backward stack operations in C.

## Objectives
- Develop algorithms for calculating factorials.
- Understand stacks and their real-life applications.
- Implement factorial calculations using forward and backward stacks.

## Files

- `backward_stack.c` – Backward stack implementation.
- `algorithms.md` – Algorithms and stack explanation.
